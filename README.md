# BudgetKeeper

Веб-приложение для учёта личных доходов и расходов с ИИ-категоризацией
операций и советами по бюджету. Учебный проект по теме № 8 учебной практики.

## Возможности

- регистрация и вход по email, восстановление пароля по одноразовой ссылке;
- клиентская (JS) и серверная валидация форм;
- ролевая модель RBAC: пользователь / администратор с декораторами
  `role_required` и `api_role_required`, проверкой владельца объекта и
  кастомной страницей 403;
- личный кабинет и панель администратора (только роль `admin`);
- счета (наличные, карта, банковский счёт) и стартовые остатки;
- собственные категории доходов и расходов;
- операции с датой, суммой, счётом, категорией и описанием;
- ИИ-подсказка категории по описанию: локальный классификатор по ключевым
  словам и опциональный вызов OpenAI-совместимого API;
- месячные бюджеты по категориям и прогресс их исполнения;
- дашборд: доходы, расходы, баланс, структура расходов, советы по бюджету;
- фильтрация операций по периоду, типу, счёту и категории;
- админ-панель Django: пользователи, операции, категории, журнал ИИ-подсказок;
- служебные маршруты `/health/` и `/api/ping/`.

## Стек

- Python 3.12;
- Django 5.2.19;
- PostgreSQL 15+ (драйвер psycopg 3.3.9);
- python-dotenv;
- HTML5, CSS3, JavaScript (fetch), Django Templates.

## Быстрый старт

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# отредактируйте .env: SECRET_KEY, DB_NAME, DB_USER, DB_PASSWORD, DB_HOST, DB_PORT

createdb budgetkeeper
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

Приложение: <http://127.0.0.1:8000/>.

### Демо-доступ

| Роль | Email | Пароль |
|---|---|---|
| Пользователь | `demo@budgetkeeper.ru` | `Demo12345!` |
| Администратор | `admin@budgetkeeper.ru` | `Admin12345!` |

`seed_demo` создаёт 30 демонстрационных операций, счета, категории и
бюджеты. Команду можно запускать повторно: она обновляет демо-данные.

### PostgreSQL в учебном окружении

На машине, где готовился отчёт, PostgreSQL 16 запущен через пакет
`pgserver` и слушает unix-сокет; путь к нему записан в локальный `.env`.
В обычном окружении достаточно указать `DB_HOST=127.0.0.1` и `DB_PORT=5432`.
Файл `.env` в репозиторий не попадает.

## ИИ-категоризация

`finance/ai.py`:

1. Если задан `OPENAI_API_KEY`, описание отправляется в
   OpenAI-совместимый API с таймаутом 12 секунд.
2. Если ключа нет или внешний API вернул ошибку, используется локальный
   классификатор по ключевым словам (словари для продуктов, транспорта,
   кафе, ЖКХ, здоровья, развлечений и т. д.).
3. Результат сохраняется в `ai_suggestions` вместе с уверенностью и
   источником (`rules` / `llm`).
4. Операция сохраняется в любом случае: сбой ИИ не блокирует работу.

## Восстановление пароля

- генерируется `secrets.token_urlsafe(32)`;
- в БД хранится только SHA-256 хеш;
- срок жизни — 30 минут (`PASSWORD_RESET_TIMEOUT = 1800`);
- токен одноразовый (`used_at`), предыдущие неиспользованные токены
  помечаются использованными;
- ответ на запрос одинаков для существующего и несуществующего email;
- на учебном стенде письмо печатается в консоль `runserver`
  (`EMAIL_BACKEND=console`).
